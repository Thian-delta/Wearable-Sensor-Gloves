1. Wearable Sensor Gloves

Low-cost wearable sensor gloves equipped with flex, pressure, gyroscope, and accelerometer sensors controlled by ESP32 microcontroller to support post-stroke hand recovery.

2. Code

The code, developed in C++ using the Arduino IDE, is programmed into the ESP32 microcontroller. It includes both the main code and test code for the flex and pressure sensors. This ensures accurate measurement of the relationship between resistance, voltage, and angles/forces.

3. Additional Files

The `additional-files` folder contains electronic schematics detailing sensor connections with the microcontroller via a breadboard, along with CAD designs of the glove's physical structure and sensor attachments.
